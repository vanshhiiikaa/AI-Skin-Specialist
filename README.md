# 🧴 AI Skin Specialist

AI Skin Specialist is an AI-powered skincare assistant designed to help users understand their skin concerns and get personalized skincare recommendations.

## ✨ Features

- 🤖 AI-powered skin analysis
- 🔍 Skin concern detection
- 🧴 Personalized skincare recommendations
- 💡 AI-generated skincare guidance
- 📸 Image-based skin analysis
- 💬 Interactive AI assistant
- 🌐 User-friendly interface

## 🛠️ Tech Stack

- Python
- Artificial Intelligence
- Machine Learning
- Computer Vision
- Generative AI
- Streamlit
- Git & GitHub

## 🚀 Installation

### 1. Clone the repository

git clone https://github.com/vanshhiiikaa/AI-Skin-Specialist.git


### 2. Navigate to the project

cd AI-Skin-Specialist


### 3. Create a virtual environment

python -m venv venv


### 4. Activate the virtual environment

#### Windows

venv\Scripts\activate


#### macOS / Linux

source venv/bin/activate


### 5. Install dependencies

pip install -r requirements.txt


## 🔐 Environment Variables

Create a `.env` file in the root directory and add your required API keys:

APIKEY=yourapikeyhere


> ⚠️ Never upload your `.env` file or API keys to GitHub.

## ▶️ Run the Application

streamlit run app.py


Open the local URL shown in the terminal to use the application.

## 🧠 How It Works

1. User provides their skin information or uploads an image.
2. The AI analyzes the provided information.
3. The system identifies possible skin concerns.
4. AI generates personalized skincare recommendations.
5. The user receives a customized skincare routine and guidance.
